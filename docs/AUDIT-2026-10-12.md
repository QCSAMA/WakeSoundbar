# Repository audit - 2026-10-12

Scope: runtime, generic/CN setup and removal, translations, release builder,
OpenSpec, security guidance and CI. The restored Administrator account was not
renamed or recreated during this audit. No registry/display settings were changed.

| Finding | Change | Verification |
| --- | --- | --- |
| No eligible target returned success | Return 3, log a diagnostic | Empty, wrong-ID and standard-target fixtures |
| Partial activation returned success | Return 2 for any failure, including a missing explicit selection | Multi-target fixture |
| Retry reused a stale snapshot | Re-enumerate before every activation attempt | Fresh-generation and disappearing-target fixtures |

| Elevated setup could bind a different account | Compare desktop SID to elevated SID; reject mismatch | Wrong-user fixture |

The source of truth for setup is now Setup-WakeSoundbar.ps1; all four batch
wrappers call it. Release ZIPs need all six files. Localized runtime scripts
retain the same control flow. Setup diagnostics are English in both editions.

## Compatibility evidence

Microsoft's [Windows 10 20H1 documentation](https://learn.microsoft.com/en-us/previous-versions/windows-insider/archive/new-in-20H1#specialized-displays-in-windows-10-enterprise-and-windows-10-pro-for-workstations)
already describes Remove display from desktop for Enterprise and Pro for
Workstations. It is not a Windows 11 24H2 introduction. The API minimum,
edition-specific Settings availability, and tested GPU/driver combinations are
different requirements. No broad Windows edition/build support was inferred
from one local workstation. The READMEs now distinguish those requirements.

## Validation and remaining checks

- 16 mocked display-runtime cases, across generic and CN scripts.
- 6 isolated setup cases, including rollback and the default source directory.
- Windows PowerShell 5.1 parsing and PSScriptAnalyzer Error-level checks.
- CN ZIP layout, ASCII wrappers, UTF-8 BOM localization and SHA-256 validation.
- Local real hardware activation and actual scheduled execution succeeded.
- Real-task XML was compared before/after isolated setup tests to verify isolation.

An early test run autoloaded ScheduledTasks and overwrote a real task action;
the original task was restored immediately. All scheduler constructors are now
test doubles, and subsequent tests confirmed the real task remained unchanged.

The local deployment was subsequently upgraded and verified. The current
account remains Administrator with its existing SID and profile. Cold-boot
behavior of this new revision still needs a real restart/login check. Other
machines, UAC cancellation in Explorer, RDP installations, new-account SID
replacement, and real uninstall require separate manual validation. Successful
DisplayState application is not proof of audio playback or HDMI codec support.
